# Financial portfolio simulator using Monte Carlo simulation methods
## Overview
I have always had a fascination with finance and the financial markets. The day I turned 18, I opened a Schwab brokerage account and purchased my first share (AAPL, if anyone is curious).
Because of the nature of financial markets, it is difficult to predict how markets will move in the future. Basic compound interest calculators exist, but these tools require you to guess what your expected yearly growth will be. 
I wanted to create a tool that can use historical market data to return a predicted value of a portfolio given a certain number of years. With this goal in mind, I began researching how financial analysts use data science to study markets, and this was the tool I built based on that knowledge.

## Installation/Usage
The program is contained in a single Python file. Once you can run the file, you can modify the main function call to experiment with different portfolios, simulation counts, starting funds, etc. 
```bash
# Clone the repository
git clone [https://github.com/NilsSmith1/Financial-Portfolio-Simulator-Project](https://github.com/NilsSmith1/Financial-Portfolio-Simulator-Project.git)

# Install required packages 
pip install numpy
pip install yfiance
pip install pandas
pip install matplotlinb
```
